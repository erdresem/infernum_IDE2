# Changelog

## Infernum IDE 0.1.0

- Introduced branded VS Code OSS distribution scaffolding based on Infernum Code 0.3.0.
- Added Editor Mode, AI Workspace and AI + Editor layouts.
- Added status-bar mode selector and Command Palette commands.
- Bundled the Infernum Code extension into the VS Code extensions directory at build time.
- Added Open VSX gallery configuration and disabled telemetry/crash reporter defaults.
- Added native Windows x64 and Linux x64 portable packaging scripts and CI workflow.
