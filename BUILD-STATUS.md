# Infernum IDE — build status

## GitHub-only build setup

The source kit is configured so the user does not need Node.js or native build tools on their own computer. GitHub Actions installs the toolchain on hosted runners:

- Node.js 24.22.1 (matches the current upstream VS Code `.nvmrc`)
- pnpm 12.16.0 (matches the current upstream VS Code `packageManager`)
- Python 3.11 and Rust stable
- Native Linux build dependencies on Ubuntu, with Microsoft's C++ toolchain preinstalled on the Windows runner

The workflow `.github/workflows/build-portable.yml` starts automatically when files are committed to `main` or `master`, and can also be started manually from the Actions page. It runs one native Windows x64 job and one native Linux x64 job, then uploads the portable ZIP and TAR.GZ artifacts.

## Local validation in this chat environment

- IDE packaging/build-helper tests: **9/9 passed**.
- Bundled Infernum Code extension tests: **24/24 passed**.
- Build scripts and WebView JavaScript syntax: checked.
- JSON manifests and settings: validated.
- VSIX archive integrity: verified.

## What has not been built here

The full VS Code OSS/Electron application binaries have **not** been produced in this chat container. A previous native build attempt was blocked before compilation because this environment could not resolve `github.com`, and this container has no Windows runner. The Windows ZIP and Linux TAR.GZ must be generated by running the prepared GitHub Actions workflow. Do not treat the source-kit ZIP or bundled extension VSIX as a standalone IDE.
